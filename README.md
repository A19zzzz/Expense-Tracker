# 支出追踪器（Expense Tracker）

一个用 Python 写的命令行支出管理工具，支持添加、删除、查看和汇总支出。

## 功能

- 添加支出（描述、金额、类别、日期）
- 更新和删除支出
- 查看所有支出，支持按类别和月份筛选
- 查看总支出或月度汇总
- 设置月度预算，超支自动警告
- 导出为 CSV 文件
